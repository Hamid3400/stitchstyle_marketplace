# StitchStyle Marketplace (Frontend Demo)

Responsive multi-tailor fashion marketplace built using HTML, CSS, and vanilla JavaScript.

## Features
- Customer sign-up and login demo
- Independent tailor registration with studio, speciality, city, and bio
- Directory that displays multiple registered tailor profiles plus sample profiles
- Product marketplace with search, category filtering, and price sorting
- Ready-to-wear shopping bag and simulated checkout
- Custom tailoring order requests and preferences
- Customer/tailor dashboard, demo orders, and message threads
- Responsive mobile navigation and layout

## Run
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser (or use Live Server).
4. Remote images and Google Fonts need an internet connection.

## Important limitation
This is a frontend-only learning prototype. Data is saved in browser `localStorage`, so accounts and messages are not shared across browsers or devices. It has no backend, database, secure authentication, live messaging, image upload, or real payment processing. Passwords are stored as plain text in localStorage for this demo; use fake credentials only. A real production marketplace needs a secure server/API, database, password hashing, authorization, secure sessions, and payment provider.
